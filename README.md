# DWGTemplateConverter

Бесплатная надстройка для AutoCAD, которая помогает привести существующий DWG-чертёж к оформлению выбранного шаблона. Программа заменяет условные обозначения и типы линий, переносит стили из шаблона и обрабатывает текстовые обозначения по заданным правилам.

## Что умеет программа

- Заменять блоки по таблице соответствий между исходными и целевыми обозначениями.
- Преобразовывать линии, полилинии, дуги, сплайны и мультилинии по настроенным правилам.
- Переносить из шаблона определения слоёв, типов линий, текстовых и размерных стилей.
- Заменять текстовые стили и преобразовывать распознанные обозначения материалов трубопроводов в блоки с атрибутами.
- Обрабатывать высотные отметки по выбранному образцу.
- Выполнять операции отдельно или запускать последовательное преобразование через графическую панель.

Обработка выполняется в пространстве модели. Результат зависит от выбранного шаблона и правил соответствия: перед первым преобразованием проверьте, какие объекты и обозначения должны быть заменены.

## Установка и первый запуск

1. Сохраните чертежи и закройте все окна AutoCAD.
2. Скачайте подходящий EXE и запустите установку. Подтвердите запрос Windows, если он появится.
3. Запустите AutoCAD и введите команду `TC_UI`, чтобы открыть панель программы.
4. Нажмите «Шаблон» и выберите DWG, из которого нужно брать целевые блоки и стили. Образец шаблона включён в установку и находится в папке «Шаблоны» установленной программы.
5. Откройте копию исходного чертежа, проверьте правила соответствия в панели и запустите нужную операцию.
6. Проверьте результат и сохраните его отдельным DWG-файлом.

Для установленной программы ручная загрузка модулей не требуется. Выбранный шаблон и пользовательские правила сохраняются в настройках вашей учётной записи Windows.

## Обновления

Программа проверяет наличие новых выпусков для вашей версии AutoCAD. Проверить обновления вручную и включить или отключить проверку при запуске можно на вкладке «Информация».

Когда появится новая версия, согласитесь на скачивание, сохраните чертежи и закройте AutoCAD. Затем подтвердите установку в Windows. После её завершения снова запустите AutoCAD.

Обновление сохраняет выбранный шаблон и пользовательские правила. Также можно скачать актуальный EXE из таблицы выше и установить его при закрытом AutoCAD.
